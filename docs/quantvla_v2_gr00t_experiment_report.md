## 2. 实验设计（被测管线）

v2 管线四阶段（详见设计文档 §6）：

1. **度量（P0-G）**：data-free 合成 obs（L1）+ 配对噪声；参照协议 = 量化管线所有目标层 `weight_bits=0`（全精度权重路径，旋转/A8 保持）；单层干预测量每层 CKA（中心化线性核）与 CS 散度（未中心化高斯核 KDE）；全局 D_solver = 纯 FP16 vs 完整配置的去噪轨迹散度（T+1 状态、γ^{k+1} 归一化权重）。
2. **选择（P1-G）**：联合 min-max 归一化 + 层重要性权重 w_i（b=4 单层干预散度，winsorize [0.5,2]）；贪心求解 `min Σ w_i·S_i` s.t. 静态权存预算；skip = 保留 FP16（成本 2P、失真 0）。
3. **部署（P2-G 运行时）**：`GR00T_DUQUANT_PLAN` env 一键接入，per-layer bit/skip 生效（per-step ATM/OHB 与动态激活 scale 按用户要求**不在本轮测试范围**）。
4. **评测**：v2 plan 配置起服务器（每套件一卡）→ LIBERO 客户端评测 → long 分片聚合。

**搜索配置（本轮实际使用）**：`--min-bits 4`（理由见 §7）、预算 = uniform-W6 静态字节数（862.9MB，四套件同）、`--solver greedy`。

## 6. 统计口径声明

- 每套件 50 条（10 任务 × 5 trials），成功率粒度为 2pp；本报告结果为**冒烟快筛口径**（设计文档 §6.5）；
- long 为 3 分片并行后聚合，分片间协议完全一致（同服务器配置、同评测参数）；
- 论文级结论需后续 3 种子 × 50 条 + task-level cluster bootstrap + 配对置换检验（§6.5 已规划）；
- 任务难度高度不均（如 goal 任务 0/9 各 0.4、long 任务 8 为 0.0），per-task 表已如实记录。

## 7. 核心发现（重要）

1. **CKA/CS 对低 bit 的"输出幅度爆炸"失明**（本实验最重要发现）：W2/W3 量化保持输出几何（CKA 不降）但幅度放大数倍，下游 A8 激活饱和 → 成功率 0%。线性 CKA 的尺度不变性与 FP 固定带宽的 CS 散度都检测不到这种失真。**修复方向**：在层代理分数中增加幅度/异常值项（如 per-channel `|amax_q − amax_ref|/|amax_ref|` 或输出 RMS 漂移），或对 CKA 使用中心化+非归一化 HSIC 变体。
2. **min-bits 约束是必要的工程护栏**：在幅度感知分数落地前，搜索空间应限制在 v1 验证过的 bit 区间（≥4）。
3. **层敏感性排序有效**：skip 集合（最敏感层保留 FP16）是分配的实际活跃成分，Long +6pp 主要由其驱动。
4. **GPU 环境动态变化**：评测期间另一会话启动 pi05 服务器挤占显存（GPU 1-4、6-7），导致一次服务器 OOM（换卡解决）与一次诊断 OOM（杀评测后解决）——多卡实验需预留显存余量（单服务器峰值 ~11GB，加载期与 pi05 共卡时不足）。

## 9. 结论与下一步

**结论**：v2 plan 完整量化版在 LIBERO 四套件上取得 **avg 87.0%**，其中 **Long 76% 超过 v1 W4A8 的 70%**（且 v2 本轮未用 ATM/OHB），spatial 98% 亦超 v1——层敏感性驱动的"敏感层保留 FP16 + 不敏感层 W4"分配策略在无尺度校正的裸量化下即达到 v1 有校正水平。实验同时暴露并定位了 v1.2 度量的关键缺陷（CKA/CS 幅度失明），并给出了可复用的工程护栏（min-bits）。

**下一步**：
1. 幅度感知分数（amax/RMS 漂移项）纳入 S_i，重跑 probe 并解除 min-bits 限制；
2. TopK 配置的全局 D_solver 裁决（`select_final()`）在 GPU 上补做；
3. 结论级统计（3 种子 × 50 条 + task-level 检验）与 libero_90 套件；
4. per-step ATM/OHB 与动态激活 scale 消融（P2-G 部署期组件）。
